# AI Student Assistant

## About the Project
An AI-powered Student Assistant developed using Python in Google Colab to help students access useful information and support their learning.

## Technologies Used
- Python
- Google Colab
- AI and Machine Learning concepts

## Features
- Student-focused assistance
- Interactive notebook-based implementation
- Python-based processing

## How to Run
1. Open the notebook file in this repository.
2. Click **Open in Colab** or upload the notebook to Google Colab.
3. Run the code cells in order.
